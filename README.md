# D&D Quarry & Aggregates

A responsive English and Albanian demo website for a quarry and aggregates supplier. Includes products, operations, projects, company information, a photo gallery, and quote/contact forms. Built with Astro, TypeScript and plain CSS; no backend required.

## Run Locally

Install **Node.js 22.12+**, then run these commands from the project folder:

```powershell
npm ci
npm run dev
```

Open **http://localhost:4321/** for English or **http://localhost:4321/sq/** for Albanian. If that port is busy, use the URL printed in the terminal. For a phone on the same Wi-Fi, use the printed Network URL.

On Windows, use `npm.cmd` instead of `npm` if PowerShell blocks the command. Press **Ctrl+C** to stop the server.

## Build

```powershell
npm run build
npm run preview
```

The production site is generated in `dist/`. Run `npm run check` for source checks.

## Demo Notice

Business details, projects and certifications are fictional. Forms validate input but **do not send or save submissions**. Replace demo content, connect a form service and set the real domain before launch; search indexing is currently disabled. See [CREDITS.md](CREDITS.md) for image sources and licences.
